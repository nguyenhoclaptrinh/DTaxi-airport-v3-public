# ATC Simulator Scenario File Schema

## 1. Mục tiêu

Scenario File Schema định nghĩa cấu trúc dữ liệu dùng để mô tả một kịch bản mô phỏng trong hệ thống ATC Simulator.

Schema phải cho phép mô tả:

- cấu hình sân bay
- danh sách máy bay tham gia
- trạng thái ban đầu của mỗi máy bay
- timeline các sự kiện
- huấn lệnh ATC
- phản hồi của pilot
- thay đổi trạng thái máy bay

Scenario file phải có khả năng:

- chạy tuần tự theo timeline
- chạy từng bước
- dừng, tiếp tục, hoặc chuyển bước

---

# 2. Định dạng file

Scenario file sử dụng định dạng JSON.

Encoding:


UTF-8


Thời gian được biểu diễn theo chuẩn:


ISO 8601


---

# 3. Cấu trúc tổng thể


Scenario
{
scenario_id: string

scenario_name: string

description: string

airport: AirportReference

aircraft: Aircraft[]

timeline: ScenarioEvent[]

}


---

# 4. Airport Reference

Xác định sân bay sử dụng trong kịch bản.


AirportReference
{
icao_code: string
airport_name: string
}


ICAO code phải tuân theo chuẩn ICAO airport identifier.

---

# 5. Aircraft Definition

Danh sách máy bay tham gia kịch bản.


Aircraft
{
aircraft_id: string

callsign: string

aircraft_type: string

initial_state: AircraftInitialState

}


---

# 6. Aircraft Initial State

Xác định trạng thái ban đầu của máy bay.


AircraftInitialState
{
state: string

position: PositionReference

speed: number

heading: number

}


---

# 7. Position Reference

Vị trí máy bay được xác định theo airport graph.


PositionReference
{
node_id: string
edge_id: string
progress: float
}


progress phải nằm trong khoảng:


0.0 ≤ progress ≤ 1.0


---

# 8. Timeline Event

Timeline là danh sách các sự kiện xảy ra trong kịch bản.


ScenarioEvent
{
event_id: string

event_time: string

event_type: string

aircraft_id: string

payload: object

}


Các event được xử lý theo thứ tự thời gian.

---

# 9. Event Types

Danh sách event_type hợp lệ:


AIRCRAFT_STATE_CHANGE
ATC_MESSAGE
PILOT_MESSAGE
AIRCRAFT_MOVE
WAIT
SYSTEM_EVENT


---

# 10. Aircraft State Change Event

Event thay đổi trạng thái máy bay.


event_type = AIRCRAFT_STATE_CHANGE


Payload:


{
new_state: string
}


new_state phải thuộc danh sách state của Aircraft State Machine.

---

# 11. ATC Message Event

Event mô tả huấn lệnh của ATC gửi cho phi công.


event_type = ATC_MESSAGE


Payload:


{
message_type: string

instruction: string

parameters: object

}


---

# 12. Pilot Message Event

Event mô tả phản hồi của phi công.


event_type = PILOT_MESSAGE


Payload:


{
response: string
}


response phải thuộc danh sách:


ROGER
WILCO
UNABLE
STANDBY


---

# 13. Aircraft Movement Event

Event mô tả di chuyển của máy bay trên taxiway.


event_type = AIRCRAFT_MOVE


Payload:


{
edge_id: string

start_progress: float

end_progress: float

speed: number

}


---

# 14. Wait Event

Event tạo khoảng dừng trong timeline.


event_type = WAIT


Payload:


{
duration_seconds: number
}


---

# 15. System Event

Event hệ thống.


event_type = SYSTEM_EVENT


Payload:


{
action: string
}


Danh sách action hợp lệ:


START_SCENARIO
PAUSE_SCENARIO
STOP_SCENARIO


---

# 16. Event Execution Rules

Các event phải thỏa mãn các điều kiện:

- event_time phải tăng dần
- aircraft_id phải tồn tại
- state change phải hợp lệ theo state machine
- movement phải hợp lệ theo airport graph

---

# 17. Scenario Validation Rules

Trước khi chạy scenario, simulator phải kiểm tra:

- airport tồn tại
- tất cả aircraft được định nghĩa
- node và edge hợp lệ
- timeline không chứa event trùng id
- timeline không chứa thời gian lùi

---

# 18. Scenario Replay

Simulator phải hỗ trợ:

- chạy lại scenario từ đầu
- chạy lại từ thời điểm bất kỳ
- tua nhanh timeline

---

# 19. Logging

Trong quá trình chạy scenario, simulator phải ghi log:


event_id
event_time
event_type
aircraft_id
execution_status


---

# 20. Khả năng mở rộng

Schema phải cho phép bổ sung các event sau trong tương lai:

- GO_AROUND
- REJECTED_TAKEOFF
- RUNWAY_CROSSING
- EMERGENCY_EVENT
- WEATHER_UPDATE
